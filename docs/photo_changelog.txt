  ADD src/photo_common.sh — sectiunea "v4.8 — PROFILE SCHEMA + VALIDATION"
    (~270 linii noi). Acopera ambele formate de profile Photo:
    - photo_profile_schema_get KEY -> "TYPE:CONSTRAINT" pentru cheile din
      UserProfiles/*.conf (KEY=VALUE: Format/Quality/Preset/...). Tipuri:

      cea pentru UserProfiles, dar keyed by --flag).

  v4.6 — HEIC HDR → Ultra HDR JPEG conversion (Samsung/Apple/generic)
───────────────────────────────────────────────────────────────

    prioritizeaza pastrarea gainmap-ului OEM (Samsung Super HDR, Apple
    Adaptive HDR), cade pe regenerare din pixeli HDR daca extragerea esueaza
  ADD --uhdr convert-preserve — forteaza pastrarea gainmap-ului OEM
    (heif-convert --with-aux -> base + gainmap -> ultrahdr_app -m 0 -a 4)

    (ffmpeg yuv420p10le -> ultrahdr_app -m 0 -a 1) — source-agnostic,
    functioneaza pe orice HEIC HDR 10-bit

    default: formula clamp(base_quality - 5, 60, 90)
